# v2.0.1 – Backups zonder IP-adressen

Backups bewaren **geen IP-adressen van bewoners** meer. De backups die al op je server staan, worden bij de eerste start na het bijwerken opgeschoond. Heb je eerder een backup van v2.0.0 gedownload? Lees dan punt 2 hieronder.

## Sinds de vorige stabiele versie (v2.0.0)

### 🔒 Backups zonder IP-adressen
- **Nieuwe backups** bevatten geen IP-adressen van bewoners, niet bij de apparaten en niet bij de blokkades. De apparaten en blokkades zelf gaan wel mee, zoals in v2.0.0.
- **Bestaande backups** in de map `backups` van je datamap worden bij de eerste start opgeschoond: de IP-adressen gaan eruit, de rest blijft gelijk, ook de logo's.
- **Uploaden:** een backup met IP-adressen (zoals een download van v2.0.0) wordt zonder IP-adressen bewaard.
- **Terugzetten** laat de IP-adressen staan die de app nu kent. Een apparaat krijgt zijn IP-adres weer bij het volgende gebruik, dus blokkeren op IP-adres blijft werken.

### 🔧 Onder de motorkap
- `express` 5.3.0 en `otpauth` 9.6.0 (Dependabot).
- Beveiligingsupdate: `body-parser` 2.4.0 en `qs` 6.17.1 (dezelfde versies als Dependabot voorstelde).
- Nieuwere versies van de GitHub Actions waarmee de app wordt gebouwd (Dependabot).
- Het image draait op **Node 22** (LTS), dezelfde versie waarmee de tests draaien. Dependabot stelt geen nieuwe Node-major meer voor; die kiezen we bewust.
- De test van het downloaden van een backup werkt weer met Express 5.3.

## Goed om te weten bij het bijwerken

**1. Geen aanpassingen aan `docker-compose.yml` of `.env` nodig.** Bijwerken kan met:
```sh
docker compose pull && docker compose up -d
```
In de containerlog staat bij de eerste start `Backups: IP-adressen van bewoners gewist uit … backup(s)` als er iets op te schonen viel.

**2. Eerder gedownloade backups van v2.0.0** staan buiten de app en bevatten nog IP-adressen van bewoners. Gooi ze weg, of upload ze één keer en download ze opnieuw: daarna zijn ze zonder IP-adressen.

**3. Niets te verversen.** De beheerpagina verandert alleen in één zin bij *Backups*.

### Installeren
```sh
docker pull ghcr.io/helmerznl/doorbell-map:v2.0.1
```
Zie [Zelf deployen met Docker](https://github.com/helmerzNL/Doorbell-Map#zelf-deployen-met-docker) voor `docker-compose.yml` en `.env`.
